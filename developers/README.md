# Developers

**Status:** Implemented — a guide to the documentation and the org workflow as they exist today.

This section is for people who want to build on Avalon, run a node, or contribute to the project. It gives a learning path through these docs and points to each repository for build and run instructions.

## Learning path: building on Avalon

1. **Orient.** [What is Avalon?](../getting-started/what-is-avalon.md), then [Concepts](../getting-started/concepts.md). Keep the [glossary](../reference/glossary.md) open.
2. **Decide if it fits.** [Integrating a game](../integrations/games.md) or [an app or service](../integrations/apps-and-services.md).
3. **Learn the model.** [Bindings](../protocol/bindings.md) (grants), [trust model](../protocol/trust-model.md) (authentic, valid, recognized), and [achievements and attestations](../protocol/achievements-and-attestations.md).
4. **Pick an SDK.** [Language support](../sdk/language-support.md), then the [SDK design](../sdk/design.md) for what every SDK guarantees.
5. **Follow the flow.** [Building an integration](../integrations/building-an-integration.md), with [capabilities](../integrations/capabilities.md), [achievements](../integrations/achievements.md), [social features](../integrations/social-features.md), and [errors and retries](../integrations/errors-and-retries.md).
6. **Run something locally.** [Running a node](running-a-node.md) for a local network, then the language guide in [avalon-sdks](https://github.com/avalon-initiative/avalon-sdks).
7. **Go deeper when needed.** [Architecture](../architecture/README.md) for how the system is shaped, and the [protocol API](../protocol/api.md) for the wire contract and conformance vectors.
