# Start here

**Status:** Partially implemented — setup paths exist for users, integrators and hosters; there is no public network yet, so first steps run against a local or development network.

Pick the role that matches what you want to do. Each row links to the guide that owns the step-by-step.

| I am... | I want to... | Go to |
| --- | --- | --- |
| A **user** of games and apps that integrate Avalon | Understand what I get and control, and set up my identity | [For users](users.md), then the Hub's [user guide](https://github.com/avalon-initiative/avalon-hub/blob/main/docs/hub/for-users.md) |
| An **integrator** building a game, app or service | Connect to a network, register, request consent and issue or verify claims | [Building an integration](../integrations/building-an-integration.md), then the language guide in [avalon-sdks](https://github.com/avalon-initiative/avalon-sdks) |
| A **hoster** running a node | Install, configure, secure, upgrade and back up a node | [Running a node](../developers/running-a-node.md), then the [hosting guides](https://github.com/avalon-initiative/avalon-protocol/blob/main/docs/projects/backend-server/for-hosters/README.md) |
| Starting **my own network** | Stand up a separate network with its own key and trust list | [Running your own network](../developers/running-your-own-network.md) |
| A **maintainer** | Bring the dev, int, staging and prod networks up and down | [Network environments](../architecture/network-environments.md) and the [runbook](https://github.com/avalon-initiative/avalon-protocol/blob/main/docs/maintainers/environments.md) |
| A **contributor** | Change code or docs | [Contributing](../developers/contributing.md) |

## What works today

There is no public mainnet. Integrators and hosters work against a node they run themselves (a local or development network) until a public network exists. Local setup for each role is in the guides above.
